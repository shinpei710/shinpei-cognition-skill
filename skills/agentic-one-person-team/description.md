# Agentic One Person Team Description

## Intent

This skill helps an agent judge AI powered one person teams, AI employee systems, multi Agent workflows, indie AI products, and personal commercial experiments.

It preserves reusable lessons from OPC and AI Agent discussions while filtering out hype. It focuses on the user's actual operating constraints: judgment, verification, context management, customer discovery, service load, cash flow, and external collaboration.

## Scope

Use this skill when the task involves:

- One Person Company, OPC, solo founder, one person team, or independent maker strategy.
- AI employees, Agent teams, multi Agent task delegation, or management Agents.
- Indie AI product ideas, personal commercial experiments, or AI assisted entrepreneurship.
- Deciding whether a product is scalable software, high touch service, consulting, or a hybrid.
- Separating a useful AI workflow from a romantic narrative about automation.

## Non Goals

Do not use this skill for:

- Routine coding tasks with no product, organizational, or commercial judgment.
- Generic startup advice when Agentic execution is irrelevant.
- Enterprise org design unrelated to personal or small AI native teams.
- Uncritical trend summaries or inspirational content.

## Usage Notes

Start with `cognitive-operating-system` when the problem is vague. Use this skill as a focused scenario module once the task clearly touches AI Agent powered personal teams or indie product judgment.

If product readiness or release gates matter, also load `cognitive-analysis-tools/system_completeness.json`. If relationship, negotiation, or collaboration dynamics dominate, use `cognitive-scenario-tools` together with this skill.
